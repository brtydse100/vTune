# v0.1.0a11 — Rebranding

Released September 2, 2026.

## What changes

- Project and distribution name: `vLLM Optimizer` / `vllm-optimizer`.
- Python package: `vllm_optimizer`.
- Primary CLI: `vllm-opt`.
- Repository: `brtydse100/vllm-optimizer`.
- The deprecated `vtune` import and CLI remain available for this release cycle.

See [Migration from vtune](../migration-vllm-optimizer.md) for exact replacements.

## Validation boundary

The public, private, documentation, workflow, and clean-package gates were run
for this rebrand. No new GPU validation was performed for a11; its runtime
behavior is inherited from the a10 benchmark-trust release.
