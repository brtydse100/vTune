# v0.1.0a13 — Software trust release candidate

_September 3, 2026_

This candidate aligns search and reporting, strengthens measurement defaults,
closes conventional secret-handling gaps, and makes coordinator failures
recoverable in persisted run state. Software gates cover Python 3.11 and 3.12,
wheel installation, tests, coverage, lint, types, strict docs, dependency audit,
SBOM generation, and tag/version consistency.

## Explicitly deferred

Native-Linux vLLM 0.28, L40/H100, tensor-parallel, multi-GPU, real long-run and
interruption cleanup, GuideLLM versus vLLM raw comparison, and the GPU smoke
workflow are **hardware validation pending**. This release makes no claim that
those checks passed.
