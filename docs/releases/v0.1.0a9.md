# v0.1.0a9

September 1, 2026. Install with `pip install "vtune==0.1.0a9"`, or add the
Linux/WSL experiment runtime with `pip install "vtune[runtime]==0.1.0a9"`.

This alpha release makes benchmark evidence easier to compare and audit:

- The public product is now **vLLM Config Tuner**; the package, import, and CLI
  remain `vtune`.
- Interactive terminal stages use color and respect `NO_COLOR`.
- Every vLLM server receives an explicit validated port.
- Complete YAML-derived commands are validated before a run starts.
- GuideLLM and vLLM results share canonical throughput, latency, and request
  count fields without inventing missing percentiles.
- Reports show per-benchmark repeat, elapsed time, median, P99, and metric
  calculation notes.

## Known alpha limitation

Do not treat long-generation GuideLLM throughput results as production evidence
without checking the raw artifacts. Request-count-only runs currently default
to a three-minute process timeout, and a backend may classify cancelled or
errored requests as processed. Set `timeouts.benchmark` explicitly, confirm the
successful/errored/incomplete totals, compare requested and observed output
tokens, and inspect `benchmark.log` plus `vllm.log`.

Strict request completion, output-length validation, and a vLLM server-drain
gate are the first items in the [trust plan](../TRUST_PLAN.md).

## Validation

The release candidate must pass the complete private suite, Python 3.11/3.12
package checks, strict documentation build, clean wheel installation, and
artifact metadata checks. The reported MiniMax long-generation behavior has
not been reproduced in the release environment.
