# v0.1.0a10

September 2, 2026. Install with `pip install "vtune==0.1.0a10"`, or add the
Linux/WSL runtime with `pip install "vtune[runtime]==0.1.0a10"`.

This alpha release prevents incomplete benchmark work from entering rankings:

- GuideLLM request-count runs and vLLM Bench Serve runs require exact, clean
  request totals before their results are accepted.
- Request-count-only GuideLLM runs receive a conservative one-hour timeout when
  no explicit benchmark timeout is configured.
- A server-drain gate verifies that vLLM has no running or waiting requests and
  saves its evidence after warmups and measured repeats.
- Rankings enforce `benchmark.min_repeats` for every configured benchmark.
- Reports include repeat uncertainty and drift evidence, with sequential reruns
  for drifted finalists.
- The release workflow tests the built wheel, produces a separate SBOM, and
  creates provenance with an immutable action revision.

## Remaining alpha limitations

Canonical normalization aligns names and units; it does not make different
backend workload semantics identical. Verify dataset, concurrency, sampling,
EOS, prompt length, and requested output length before comparing GuideLLM with
vLLM Bench Serve. Exact output-token fulfillment is not yet independently
validated beyond each backend's reported request completion.

Hardware validation is intentionally outside this release-candidate check.

## Validation

The release candidate must pass public and private behavioral suites, strict
documentation, source and wheel builds, Twine checks, clean wheel installation,
and a local simulation of the publish job.
